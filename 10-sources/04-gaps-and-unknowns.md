# 10.4 · Gaps and Unknowns

*Part of [10 · Sources](README.md)*

What this research could not establish. Stated honestly, because a decision-maker needs to know where the

## 1. The ten most important unknowns

| # | Unknown | Why it matters | How to resolve |
|---|---|---|---|
| 1 | **What net price gain a platform can actually deliver** | The entire value proposition | Pilot with matched comparison group |
| 2 | **Whether farmers will repeat after one season** | Determines unit economics | Cohort tracking over 2 seasons |

| 9 | **The security trajectory in Amhara and Oromia** | Determines regional viability | Ongoing monitoring |

## 2. Data gaps by domain

### 2.1 Agriculture

| Gap | Consequence |
|---|---|
| No reliable farm-level production data | Sizing relies on national aggregates |
| Post-harvest loss figures vary 15–30% | Cannot quantify the loss-reduction value |
| Cooperative activity is undocumented | Cannot estimate the active cooperative count |
| Land tenure records incomplete | Credit collateral impossible to assess |
| Crop quality/grading data absent | Cannot model premium potential |
| No data on trader margins by region | Cannot size the intermediary spread precisely |

### 2.2 Finance

| Gap | Consequence |
|---|---|
| Ag credit demand (ETB 2.58 tn) is a single estimate | The "2% met" statistic is directionally, not precisely, true |
| No smallholder credit performance data | Cannot model default rates before lending |
| Informal credit volumes unknown | Total credit access is understated |
| Insurance penetration by crop unknown | Cannot size the insurance opportunity |
| No data on loan sizes actually demanded | Product design relies on assumptions |

### 2.3 Digital

| Gap | Consequence |
|---|---|
| Smartphone penetration definition unclear | Cannot size the app-addressable market precisely |
| Rural internet use (9%) is modelled, not measured | Could be worse |
| USSD session costs not publicly documented | Cannot model SMS/USSD costs precisely |
| Agent-level mobile money economics unknown | Agent income model is an estimate |
| Digital literacy levels unmeasured | Channel design relies on literacy proxies |

### 2.4 Market structure

| Gap | Consequence |
|---|---|
| Number and size of traders unknown | Cannot assess incumbent strength |
| Buyer concentration unknown | Cannot assess market power |
| E-commerce market size unreliable | Sector sizing abandoned |
| Competitor financials unavailable | Cannot benchmark |
| Cooperative financial health unknown | Onboarding cost uncertain |

## 3. Methodological gaps

| Gap | Effect | Mitigation |
|---|---|---|
| **No fieldwork** | Behavioural claims are inferences | Pilot is the primary research |
| **No stakeholder interviews** | Government, bank, telco intentions inferred | Direct engagement in Phase 0 |
| **English-language bias** | Amharic sources under-used | Commission Amharic research |
| **No access to internal data** | Operator economics opaque | Partnership negotiations |
| **Fast-changing environment** | Figures date within months | Quarterly update |
| **No independent econometric analysis** | All quantitative claims are secondary | Commission an independent study |

## 4. Questions that would change the recommendation

| Question | If the answer is… | Then… |
|---|---|---|
| Can farmers get ≥5% net more? | No | **Stop.** The thesis fails |
| Is escrow legal via a bank partner? | No | Restructure or stop |
| Will lenders lend on ledger data? | No | Become a data provider, not an originator |
| Is a state platform imminent? | Yes | Partner; do not compete |
| Is conflict spreading to Oromia? | Yes | Delay or reduce to one region |
| Can agents earn ≥ETB 30k/yr? | No | Change distribution model |
| Is capital available for 7 years? | No | Reduce scope to a profitable regional business |

## 6. Known-unknowns vs. unknown-unknowns

| Type | Examples |
|---|---|
| **Known unknowns** (identified above) | Price gain, repeat rate, agent income, regulatory position |
| **Unknown unknowns** | The things that will actually determine the outcome — a minister's decision, a security incident, a currency crisis, a technology shift |

**No research eliminates unknown unknowns.** The plan's response is structural: light assets,
diversified regions, feature flags, cash reserves, and gates that stop spending when the evidence turns
negative.

---

## 7. The honest summary

> This repository is a **rigorous desk study**. It has verified ~60 factual claims, corrected 14 errors
> in the source brief, and built a coherent analytical structure. It has **not** tested a single
> behavioural assumption with a real farmer.
>
> The recommendation is therefore conditional: *if* farmers will switch for a meaningful net price gain,
> *if* escrow can be done legally, *if* agents can earn a living, and *if* the security situation permits
> operations — then the platform is a strong opportunity.
>
> The pilot exists to test the *if*s at a cost of ~ETB 40 m, rather than at a cost of ETB 1 bn.
